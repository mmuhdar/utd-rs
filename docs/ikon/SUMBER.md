# Sumber ikon README

- Logo teknologi (`rust.svg`, `svelte.svg`, `postgresql.svg`, dan seterusnya) dari [Simple Icons](https://simpleicons.org/) (CC0 1.0). Merek dagang tetap milik pemiliknya masing-masing; logo dipakai hanya untuk menunjukkan teknologi yang digunakan.
- Ikon umum `lucide-*.svg` dari [Lucide](https://lucide.dev/) (lisensi ISC), digambar ulang dengan garis abu-abu `#8b949e` supaya terbaca di mode terang dan gelap.
- `figcraft.png` adalah ikon aplikasi [FigCraft](https://getartcraft.com/apps/figcraft) (MIT/Apache-2.0).
- Ikon berwarna hitam (Rust, Tokio, JSON) memuat varian warna untuk `prefers-color-scheme: dark`.
