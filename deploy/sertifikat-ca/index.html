Pasang sertifikat utd-rs

utd-rs berjalan di jaringan lokal rumah sakit dan memakai sertifikat HTTPS yang diterbitkan server ini sendiri. Pasang sertifikat akar (root CA) di bawah ini sekali saja di setiap komputer dan tablet, supaya browser tidak lagi menampilkan peringatan "koneksi tidak aman".

Unduh sertifikat (utd-rs-root-ca.crt)

Untuk memastikan berkasnya asli, cocokkan sidik jari SHA-256 dengan yang diberikan admin TI.

Windows (Chrome, Edge)

  1. Buka berkas yang diunduh, lalu klik Install Certificate… / Pasang Sertifikat…
  2. Pilih Local Machine (perlu izin administrator), lalu Next.
  3. Pilih Place all certificates in the following store → Browse… → Trusted Root Certification Authorities.
  4. Next → Finish, lalu tutup dan buka lagi browser.

Firefox (semua sistem)

  1. Buka Pengaturan → Privasi & Keamanan → Sertifikat → Lihat Sertifikat…
  2. Tab Otoritas → Impor…, pilih berkas, centang Percayai CA ini untuk mengidentifikasi situs web.

Android (tablet ruang)

  1. Unduh berkasnya.
  2. Buka Setelan → Keamanan & privasi → Setelan keamanan lainnya → Enkripsi & kredensial → Instal sertifikat → Sertifikat CA (nama menu bisa sedikit berbeda per merek).
  3. Pilih Tetap instal, lalu pilih berkas utd-rs-root-ca.crt.

iPad / iPhone

  1. Buka halaman ini di Safari, unduh, lalu pilih Izinkan.
  2. Pengaturan → Profil Diunduh → Instal.
  3. Pengaturan → Umum → Mengenai → Pengaturan Kepercayaan Sertifikat, aktifkan sertifikat Caddy Local Authority.

Linux (Ubuntu)

  1. sudo cp utd-rs-root-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates
  2. Chrome/Chromium: Setelan → Privasi dan keamanan → Keamanan → Kelola sertifikat, impor di tab Otoritas.

Sertifikat ini hanya berlaku untuk server utd-rs di jaringan rumah sakit dan masa berlakunya 10 tahun. Jangan memasang sertifikat dari alamat lain yang tidak diberikan admin TI.
